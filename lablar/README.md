# Laboratuvar betikleri

## `oku-sistem.sh`

Yerel sistem bilgilerini salt okunur biçimde görüntüler. Paket kurmaz, dosyaya yazmaz, dosya silmez, servis değiştirmez ve sudo çağırmaz.

```sh
sh lablar/oku-sistem.sh
```

Çıktı bazı süreç adlarını, disk durumunu, kullanıcı kimliğini ve dinleyen TCP portlarını gösterebilir. Çıktıyı herkese açık paylaşmadan önce kişisel veya kurumsal ayrıntıları kontrol et.

Bu betik öğretici bir başlangıçtır; kapsamlı güvenlik taraması, sistem sertifikasyonu veya adli inceleme aracı değildir.
